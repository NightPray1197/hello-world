· feat：新功能（Feature）。比如你点亮了 LED、调通了串口。
  · 例子：feat: 完成 LED 点灯
· fix：修复 Bug。比如串口乱码修好了。
  · 例子：fix: 修复按键抖动导致误触发
· docs：只修改了文档（Documentation）。比如只改了 .md 笔记。
  · 例子：docs: 补充定时器中断学习笔记
· style：代码格式变动，不影响代码逻辑（比如加了空格、换行、删了多余的分号）。
  · 例子：style: 格式化 main.c 代码
· refactor：重构代码。既没有加新功能，也没有修 Bug，只是让代码结构更清晰了。
  · 例子：refactor: 将按键检测提取为独立函数
· chore：杂务。不修改源码和逻辑，比如修改 .gitignore、更新库文件、修改构建脚本等。
  · 例子：chore: 添加 .gitignore 忽略规则
· test：添加或修改测试代码。
· perf：性能优化。
